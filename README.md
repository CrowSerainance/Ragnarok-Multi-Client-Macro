# Ragnarok Multi-Client Macro

Ragnarok Multi-Client Macro is a Ragnarok Online automation and macro utility focused on smoother multi-client control, configurable hotkey bindings, skill-spam workflows, profile-based setup, and improved client interaction behavior.

This project builds on foundations laid by earlier developers and toolmakers while carrying my own improvements, refinements, fixes, and quality-of-life upgrades forward. I expanded and polished the existing base with better macro handling, improved AHK/profile behavior, UI/UX upgrades, dynamic Auto-Skill visibility, clearer hotkey management, more robust client targeting, and fixes for click execution behavior.

Key improvements include configurable macro slots, improved parsing and controls, loop-mode support, per-key timing, profile persistence, better handling of bound Ragnarok clients, and refined click execution with adjustable click speed. Recent updates also separate click handling into a more reliable per-slot autoclicker flow, allowing left-click execution to behave more consistently while a trigger is held.

At its core, this repository represents both preservation and iteration: the foundation was laid before me, but the current direction, fixes, and usability improvements were shaped and improved by me.
